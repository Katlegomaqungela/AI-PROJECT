# AI-PROJECT
Creating 5 applications: Smart Email Generator, AI Task planner, AI Chatbot interface, meeting notes summariser and AI research Assistant 
Here is the final, consolidated prompt for SpaceGem, combining the complete functionality, UX requirements, and the new futuristic space-inspired branding into one prompt you can paste directly into an AI app builder.

MASTER BUILD PROMPT — SPACEGEM AI WORKPLACE ASSISTANT

Build a polished, professional, responsive AI productivity web application called SpaceGem.

SpaceGem is an all-in-one AI Workplace Productivity Assistant designed to help students, professionals, entrepreneurs, and teams write better, understand information faster, organize their workload, conduct research, and communicate more effectively.

The application should feel like a premium futuristic AI command centre in outer space while remaining extremely easy and intuitive to use.

The final product must feel like a real commercial SaaS product, not a collection of demo screens.

2. CORE PRODUCT IDEA

SpaceGem should bring five powerful AI tools into one connected workspace:

1. Smart Email Generator

Generate polished professional emails in seconds.

2. Meeting Notes Summarizer

Turn lengthy meeting notes into concise summaries, decisions, action items, and deadlines.

3. AI Task Planner & Scheduler

Create realistic daily and weekly schedules and intelligently prioritize tasks.

4. AI Research Assistant

Research and understand topics, summarize information, provide insights, and generate recommendations.

5. AI Workplace Chatbot

A conversational AI assistant that helps users with writing, planning, research, productivity, and everyday workplace questions.

These features must feel like parts of one intelligent ecosystem, not five unrelated tools.

3. CONNECTED AI WORKFLOWS

Create workflows between the different tools.

For example:

Meeting Notes → Summary → Action Items → Tasks → Schedule

A user should be able to summarize meeting notes and then send extracted action items directly to their task planner.

Another workflow:

Research → Findings → Summary → Report → Task

Another:

AI Chat → Email → Edit → Copy

Another:

AI Chat → Task → Schedule

Where technically possible, allow information to move between tools without requiring the user to manually copy and paste everything.

This interconnected experience should be one of SpaceGem's key differentiators.
